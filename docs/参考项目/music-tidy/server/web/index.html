重复文件

综合检查 = 内容重复（文件字节完全一致）+ 名称重复（歌手+歌名相同但内容不同，如同一首歌的 flac/320k 双版本）。内容组默认保留最优文件；名称组默认保留无损/高码率版本；「AI 去重」会逐组调用大模型按音质/命名/路径判断保留项，AI 失败时自动回退默认策略。

重复封面检测

同一张封面图出现在多个不同目录的歌曲上，通常是刮削匹配错了。点「检测」列出可疑组，再点「AI 重新获取并更换」逐首识别歌手/歌名并从曲库重新下载封面（需先在设置页启用 LLM；同专辑共用封面属正常，不会误报）。
