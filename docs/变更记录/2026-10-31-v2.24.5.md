# 2026-10-31 v2.24.5 向导目录改可选 + 应用内盘位选择器

> 承接同日的 v2.24.4（官方权限模型重做）。用户反馈两条：安装向导里的曲库目录不该强制必填；
> 向导里想有「手动选目录」的按钮，默认能看见各盘位根目录、最好还能新建文件夹，
> 并要我按官方文档确认这是否做得到。

## 一、官方文档的结论（先查再改）

查了 `developer.fnnas.com` 的四个页面，结论是一次性说死的：

| 页面 | 结论 |
| --- | --- |
| `/docs/core-concepts/wizard/` | 向导**只有**七种字段类型：`text` / `password` / `radio` / `checkbox` / `select` / `switch` / `tips`。没有文件或目录选择器，也没有「按钮」这个概念。`rules` 只支持 `required` / `min` / `max` / `len` / `pattern`。 |
| `/docs/core-concepts/environment-variables/` | 向导值只作为**环境变量**交给生命周期脚本（`field` 名 = 变量名）。应用后端是常驻进程，重启后再也拿不到 —— 所以由 `cmd/_wizard` 落到 `${VAR_DIR}/env.d/`。 |
| `/api/authorization/user-access/` | `pickUserFile({directory:true})` 是**前端 JS SDK** 才能调的，而且它要等应用装完、页面起来、SDK 连上宿主才存在。 |
| `/api/page/routing/` | `openFileManager(path)` / `openAppSetting()` 同理，全是前端 SDK，靠 `micro_app=true` 生效。 |

**所以「向导里放一个选目录按钮、默认显示盘位根目录」在飞牛的平台能力上做不到**，
不是实现偷懒：向导渲染器是宿主写死的表单，应用塞不进自定义控件。**没有**任何官方 API
能在安装阶段弹出文件选择器。

能做的是两件事，本次都做了：

1. 向导里放 `tips` 把原因和替代路径写清楚（用户不会以为是自己没找到按钮）；
2. 把「选目录」挪到**应用内**，用官方 `pickUserFile` / `pickSharedFile` 调起
   宿主自己的文件选择器 —— 那里有完整盘位视图，`creatable: true` 时宿主还会给
   「新建文件夹」入口。

## 二、向导改动

`fpk-package/wizard/install`：

- `wizard_music_dir` 去掉 `required`，`rules` 只剩下 `pattern: "^$|^/.*"`，标签改成
  「本地曲库目录（可选，可留空）」，`initValue` 保留 `/vol1/Music` 当建议值。
- `helpText` 里加盘位速查：`/vol1`…`/vol9` 是各存储空间根目录，`/vol1/1000` 这类
  `<盘位>/<用户ID>` 是个人文件夹。这是**替代**「点按钮看盘位」的最低成本办法。
- 新增两条 `tips`：一条讲「可以先不填，装完再设」并指向应用内按钮；一条讲
  「为什么向导里不能直接选目录」（纯表单、七种输入、SDK 要装完才有）。

`fpk-package/wizard/config`：同样去掉必填，改成「留空 = 不改动当前设置」。

`fpk-package/cmd/_wizard`：只加注释，说明「留空 = 不改动」的承诺**依赖**
`if [ -n "$music" ]` 那段判断 —— 这两个字段一旦标回 `required`，用户就没法
「只改别的、不动目录」了。逻辑本身没动（空值本来就跳过）。

## 三、应用内盘位选择器

`frontend/src/services/trimHost.js`：

- `pickDirectory()` 与 `pickSharedDirectory()` 都透传 `creatable: true` 和
  `sidebarGroup: ['myFiles','otherShare','external']`。
- `sidebarGroup` 的选择理由：官方 `FilePickerParams` 里**没有**「初始路径」参数，
  唯一能影响「从哪儿开始看」的就是左侧分组。露出「我的文件 / 其他共享 / 外接存储」
  三组，盘位就是从这三处进去的。想直接落在某个具体盘位目录上，接口不支持。
- 注释里写清这两点的依据，避免下轮有人以为漏了什么参数。

`frontend/src/components/AppSettings.vue`（存储目录区块）：

- 新增一块绿色边框的「用飞牛的文件选择器选曲库目录」+「浏览盘位选择」按钮，
  `v-if="hasTrimPicker()"` —— 只在飞牛宿主里出现，普通浏览器/预览模式不显示死按钮。
- 选中后**只填进输入框**并提示「确认无误后点保存目录」，不静默落盘：下载目录与曲库目录
  是同一个字段，且用户可能只是想看看。
- 和原有 `NasDirPicker` 的分工写进注释：`NasDirPicker` 只在**已授权**范围内浏览，
  曲库没授权时它根目录都是空的；官方选择器看全部盘位且选中即授权，是「第一次配曲库」
  的正确入口。

## 五、一个仍然存在的差距

「默认显示当前磁盘根目录按钮」这个体验，官方选择器给不了 —— 它没有 `defaultPath`
参数，只能靠 `sidebarGroup` 让左侧露出盘位分组，用户仍要自己点一次「我的文件」。
如果后续飞牛加了该参数，只需在 `trimHost.js` 的 `pickDirectory()` 里补一行。
