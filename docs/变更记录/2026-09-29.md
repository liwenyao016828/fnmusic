#### 二、几个必须记住的点

- **光晕不能省**：只做模糊背景 + 圆角封面，封面仍像「贴上去的一张图」。第二张同 src 的 img（`blur(46px)`、`scale(1.04)`）
  才让封面边界「化」进背景。浏览器对同一 URL 复用同一份资源，**不额外发请求**。
- **`aspect-square` + `max-h-full` 是对的组合**：宽度由 `clamp(180px,74vw,360px)` 定，高度由宽高比推，超出容器时 `max-h-full` 兜住，
  `object-cover` 只裁不拉伸 → 矮屏（横屏/小屏）封面比例稳定，不会变形。**别把 `max-h-full` 换成固定高度**。
- **safe-area 只挂外层**：`pt-safe` / `pb-safe` 挂在最外节点、视觉 padding 挂内层 —— 本项目既有规矩（同节点会互相覆盖，2.1.43 踩过）。
- **根节点显式 `height: 100dvh`**：`fixed inset-0` 之上再给高度，`top/bottom/height` 同时存在时 `bottom` 被忽略，等于精确 dvh（iOS 地址栏收放跟得上）。
- **桌面端去掉了 emerald 强调**（进度条 + 播放键改白）：用户要求「桌面端和移动端保持同一套视觉语言」，绿色属于旧口径。
  要恢复绿色只改 `.ys-ip-play` 的 background 与两处 `bg-white` 即可。
- `<style>` 用的是**全局**（非 scoped）+ `ys-ip-` 前缀，和 `style.css` 里 `ys-glass` / `ys-ambient__*` 一套做法，不冲突。

#### 二之补：矮屏两道保险（首轮实测暴露出来的）

首轮量完才发现两个**只有矮屏才会犯**的错，都已修：

| 症状（实测） | 原因 | 修法 |
|---|---|---|
| **封面框不是正方形**：390×600 下 288.6×277.5 | `aspect-square` + `max-h-full`：宽由 `74vw` 定死、高被容器夹住 → 比例被破坏（图只裁不拉伸，但框变成扁的） | 换成**容器查询**：`.ys-ip-stage { container-type: size }` + `.ys-ip-cover { width: min(100cqw - 36px, 100cqh - 12px, 360px) }`，永远取舞台**较短边**当边长 |
| **横屏 844×390 封面塌成 13.5×13.5** | 桌面分栏里封面舞台是 `flex-1`，信息+进度+控制器（≈200px）先把竖向空间吃掉 | `@media (min-width:768px) and (max-height:560px)` 下**让出封面**（`.ys-ip-desktop-cover { display:none }`），其余完整不重叠 |
| 横屏 667×375（<md 走手机布局）封面只剩 40.5px | 玻璃面板固定 250px 吃掉竖向空间 | `@media (max-width:767px) and (max-height:620px)` 收紧面板（隐藏词曲行 / 压缩间距 / 播放键 68→56），封面回到 89px |

⚠️ 别改成「给封面加 `min-height`」—— 会反过来盖住下面的信息区。

**发现一个既有 bug（不是本轮引入，未改）**：沉浸页进度条的点击跳转是**死代码** —— `handleSeek` 读 `progressBarRef`，
但模板里从来没有 `ref="progressBarRef"` 这个绑定（上一版也没有），所以点击进度条不会 seek（实测点 55% 后
`currentTime` 不动、音轨继续按自己的节奏走）。修法是给进度条容器补一个 `ref="progressBarRef"`，一行；
但「补上」= 改变交互，所以先报给用户裁示。
