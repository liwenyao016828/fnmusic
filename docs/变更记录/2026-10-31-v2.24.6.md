# 2026-10-31 v2.24.6 向导去掉提示文字

> 用户口径：「安装向导不需要那些提示文字」。

## 改了什么

`fpk-package/wizard/` 下三个文件全部重写，只剩字段：

| 文件 | 内容 |
| --- | --- |
| `install` | 步骤「曲库目录（可选）」+ `wizard_music_dir`（本地曲库目录）+ `wizard_watch_dirs`（额外曲库目录） |
| `config` | 与 install 相同（构建期用一份模板重建，避免两份漂移） |
| `uninstall` | 步骤「卸载选项」+ `wizard_keep_data` 单选（保留 / 删除） |

具体做法：

- **删掉全部 `tips`** —— v2.24.5 里为讲「为什么向导不能选目录」「装完怎么授权」加的三段提示全部移除。
- **删掉全部 `helpText`** —— 曲库目录、额外曲库目录的说明文字一并去掉。
- **删掉全部 `rules`** —— 目录字段本来就已改可选，剩下的 `pattern: "^$|^/.*"` 也是提示性校验，一起去掉后填错也不会被拦，与「只留输入框」一致。
- **`initValue` 移除** —— 以前 install 预填 `/vol1/Music`，现在改成 `placeholder`（浅色占位符），不改用户没碰过的输入框。
- 卸载项的标签从「先备份再卸载 / 直接卸载，不备份」缩成「保留 / 删除」，选项文案同样属于提示文字。

## 连带影响

- `cmd/_wizard` 的 `qulv_apply_wizard` 本来就只接受 `/` 开头的绝对路径、空值跳过，去掉正则校验后**后端仍会自己拒掉非法值**（只打一行警告，不写 env.d）。这一点没变，所以去掉前端校验不会让脏值进配置。
- 「留空 = 不改动当前设置」的语义没变，仍靠 `if [ -n ]` 那段判断。

## 验证

- 三个 wizard 文件 `json.loads` 通过，并脚本断言：无 `tips` 类型、非 tips 字段全部 `wizard_` 前缀。
- `python3 scripts/build_fpk.py` 打包自检通过；`tar -xzOf yinshu-ai.fpk wizard/install` 确认包里就是上面这份纯字段版本，`grep -c tips` 为 0。
- 本次只动 `fpk-package/wizard/` 与版本号，未动 Go/前端代码，故未重跑 `go test` 与前端测试。
