# v2.24.11 · 选目录直接用飞牛文件选择器 + 手机端修复

日期：2026-10-31
类型：功能微调 / 缺陷修复（patch）

## 用户诉求（原话）

> 飞牛桌面点开曲率 → 顶部应出现琥珀提示条 → 点「授权目录」→ 应弹出飞牛文件选择器。
> 我觉得用和点击选择后可以不需要出我自己的目录选择器了，直接用飞牛的文件选择器。

> 移动端里，我在飞牛 app 里打开应用，为什么就没出现飞牛选择器。

## 结论

1. 点「授权目录」「选择」一律**先调飞牛宿主的文件选择器**，不再先弹自绘的 `NasDirPicker` 目录树。
2. 手机端（飞牛 App 内嵌 WebView）之前**从不弹选择器**，是探测判据的问题，本轮修掉。
3. 选完目录即视为授权完成，不再要求回应用设置手动授权一遍。

## 根因

### 一、手机端判据恒 false

`@trimjs/web-app@0.5.0/dist/index.js` 实测：UA 含 `FNAppVer/` 时 `isWeb=false`，
走 `initMobileAppApi(window.flutter_inappwebview)`；`getHostCapabilities()` 直接返回
`{runtime:"mobile"}`，**`osConnector` 恒为 null** —— 旧判据 `osConnector.methods.pickSharedFile`
在手机端永远拿不到，于是所有授权按钮判成"不在宿主里"，选择器一次都弹不出来。

### 二、自绘弹窗是多余的一层

`NasDirPicker.vue` 原本是唯一消费方，飞牛按钮只是弹窗内第三行。用户要点两次才见到飞牛选择器，
且弹窗本身在未授权时目录树是空的，等于没有意义。

### 三、选完要等一会儿才读得到

授权后 `pathguard` 的授权目录缓存还在用旧值，用户选完立刻回目录列表可能仍是 403。

## 改动

### 前端

- `frontend/src/services/trimHost.js`
  - 新增主导出 `chooseDirectory({title, okText, creatable})` → `{ok, path, cancelled, error, fallback}`：
    宿主内调飞牛选择器；非宿主返回 `fallback: true`，由调用方回落自绘弹窗。
  - 新增 `mobileBridgeReady(app)`：判 `app.flutterInAppWebView` 存在即视为移动端桥接可用。
  - 探活改 `bridgeSupportsPicker(osConnector.methods) || mobileBridgeReady(app)`；`runtime` 标 `desktop`/`mobile`。
- `frontend/src/components/AppSettings.vue`
  - 新增琥珀提示条 `showAuthBar = shouldPrompt()`，动作「授权目录」+「打开应用设置」。
  - 三个「选择」按钮改走 `chooseDirFor()`（先飞牛选择器，不可用才落自绘弹窗）；删掉原绿色飞牛选择块与 `pickTrimDir`。
- `frontend/src/components/TidyDirChip.vue`：chip 直连 `chooseDirectory()`；**读不了就不写入**，不再静默落一个无权访问的目录。
- `frontend/src/components/FnosAuthNotice.vue`：`grantDir` 改走 `refreshAuthStatus` + `picked.readable`。
- `frontend/src/services/fnosAuth.js`：新增 `lastPick` ref 与 `refreshAuthStatus(path)`，解析 `picked_readable` / `picked_hint`。
- `frontend/src/api/client.js`：`FnosAPI.authRefresh(opts)` 支持 `params.path`。

### 后端

- `backend/pkg/nas/pathguard.go`：授权成功后开一个**缓存不信任窗口**
  （`rootsStaleWindow = 20s`、`rootsStaleMinInterval = 1500ms`、`NoteFnOSRootsStale()`），
  窗口内授权目录缓存条件加 `!fnosRootsStaleNow()`，即重新向系统取一次。
  **安全边界未改**：越权仍是 `ErrPathForbidden` 403。
- `backend/pkg/api/fnos_auth.go`：`HandleFnosAuthRefresh` 支持可选 query `path`，
  返回 `picked_path` / `picked_real_path` / `picked_readable` / `picked_hint`。

## 测试

- `frontend/src/services/trimHost.test.mjs`：7/7 通过（新增 2 例移动端判据）。
- `backend/pkg/nas/pathguard_roots_test.go`：新增 3 例 stale-window。
- `go test ./...` 全包 ok；`vite build` 1867 modules 通过。
- 接口实测：`POST /api/fnos/auth-refresh?path=<x>` 回 200 且含 `picked_path` / `picked_readable` / `picked_hint`。

## 未验

- 真机桌面端：点开曲率 → 琥珀提示条 → 点「授权目录」→ 弹飞牛选择器 → 选中后目录树出现。
- 真机手机端：飞牛 App 内打开曲率 → 选择器能弹出。
- 若真机 UA 不含 `FNAppVer/`（走 `isWeb` 分支且不是 iframe），或 appApi 版本低于 `1.0`
  （`assertMobileAppApi` 抛错），仍需再补一轮判据。

## 已知系统侧问题（不影响本轮）

应用中心与 `trim_open_gateway` 版本不配套、系统仅有自签证书导致开放 API token 降级 ——
授权走的是前端 JS SDK，不经开放 API。
