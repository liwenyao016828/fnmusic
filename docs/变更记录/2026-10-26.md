# 2026-10-26

## v2.22.0 隐藏目录可见（`.dev/music` 在目录选择器里翻不到）

用户报障原话：「`music-v2/.dev/music` 中间的 `.dev` 在目录选择器中看不到」。
他的下载目录配置本来就是 `/home/liwenyao/projects/music-v2/.dev/music`，所以这不是「找不到路径」，
而是**界面上没有任何一处能把这个目录摆出来给他选**。

### 1. 根因：接口根本没有 `hidden`，前端连了也是白连

`backend/pkg/nas/scanner.go` 的 `BrowseDirectory` 在扫目录时无条件 `continue` 掉 `.`/`$`/`@` 开头的条目 ——
**服务端从来没有过 `hidden` 参数**。上一轮虽然已经给 `NasDirPicker.vue` / `NasExplorer.vue` 加了
「显示隐藏目录」开关、并且前端也在传 `hidden=1`，但后端直接忽略未知查询参数：开关按下去数据不变，
用户看到的就是「这个目录不存在」。这正是「前端改了但现象没变」的典型 —— 只验前端看不出问题，必须打通到接口。

同一条链路上还有第二处：`frontend/src/services/downloadManager.js` 的 `browseDir()` 压根没传 `hidden`，
「设置保存目录」弹窗（`DownloadDirModal.vue`）这条路连开关都没有。

### 2. 后端（`backend/pkg/nas/scanner.go`、`backend/pkg/api/catalog.go`）

- `hidden=1` 时不再跳过隐藏项（`wantHidden`），`@eaDir`/`$RECYCLE.BIN` 这类系统目录也一并带出。
  默认行为不变：仍然是藏起来的（`.tidy_trash` 不该被选成曲库根）。
- `BrowseData` 新增 `hidden_count` / `hidden_dirs`：**被折叠掉的子目录**数量与前 12 个名字。
  只统计目录（列表里本来只有目录）。这两个字段是给「开关就在眼前但用户没看见」兜底用的 ——
  前端不只能靠一个复选框，还能直接写一句「这一层还有 13 个隐藏文件夹（.dev、.git…）· 点这里显示」。
- 目录里的二级目录扫描那处（`has_subdirs`/`audio_count` 预扫）也跟着受 `wantHidden` 控制。
- `catalog.go` 登记 `hidden` 参数与两个新字段的语义（项目约定：新接口/参数必须进 catalog；
  `node .dev/catalog-audit.mjs` 复核「源码 166 条 / 线上 166 条一致」）。

### 3. 前端（三处选择器 + 一个兜底提示）

- `DownloadDirModal.vue`：新增「显示隐藏目录」复选框 + 「上一级」，并挂上 `hidden_count` 提示条；
  空列表时的文案区分「真的空」与「只有隐藏目录」。
- `services/downloadManager.js`：`browseDir()` 传 `hidden: browseShowHidden.value`；新增
  `setBrowseShowHidden()`（写偏好 + **就地重读当前目录**，不跳回上一层），打开弹窗时重读偏好
  （用户可能在另一个弹窗里刚切过）。偏好键 `nas_show_hidden` 与 `NasDirPicker.vue`、`NasExplorer.vue` 共用。
- `NasExplorer.vue`：「添加曲库目录」弹窗加同样的 `hidden_count` 提示条（开关上一轮已有）。
- `NasDirPicker.vue`：上一轮已有开关与提示条，本轮因为后端补上 `hidden` 才真正生效。

### 4. 验证（真机 / 真接口 / 真 DOM，不只 build 通过）

- 重建 `.dev/fn-dev-backend`（`go build -o .dev/fn-dev-backend .`）并重启 8900。
- 接口：`/api/nas/browse?path=<repo>` 默认 → `folders` 无 `.dev`，`hidden_count=13`，
  `hidden_dirs` 头几个是 `.dev/.git/.github/.npm-cache`；加 `&hidden=1` → `.dev` 出现且 `hidden_count=0`；
  `/api/nas/browse?path=<repo>/.dev&hidden=1` → 列出 `music` 等子目录，**这就是用户要选的那一层**。

  点这句提示 → `.dev` 出现在列表、提示消失、**路径没变**（没有跳回上一层）。
- 测试：`go test ./pkg/nas/ ./pkg/api/` ok；`gofmt` 干净；`go vet` 通过；
