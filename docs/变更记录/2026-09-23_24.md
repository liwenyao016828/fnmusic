**教训**：用户点名参考某个实现时，**先把那个实现拆开看完再动手**，别照自己想象补一版。

flow 的做法（`app.tgz` → `docker/app/static/index.html`，函数 `renderOnboarding()` / `stepMarkup()` / CSS `.fnmf-*`）：

- 页顶一块**独立引导卡**（不是塞在标题栏的小字），头部 = eyebrow「首次使用」+ h2（未完成「三步即可开始」/
  完成「一切就绪，开始听歌吧」）+ 一句说明 + **右上角 `N / 3` 进度胶囊** + 「暂时隐藏 / 收起」按钮；

  （「已导入 N 个音源，其中可用 M 个」），卡底**一个跳到该做那件事的按钮**（去上传音源 / 一键绑定 / 去搜索歌曲）；
- `.fnmf-step.done` 只改边框和底色（绿），不隐藏卡片；
- **收起只由用户点**（`HIDE_KEY`），三步没做完时点「暂时隐藏」也还是会显示 —— 把引导藏起来等于把卡住他的人的入口藏起来。
